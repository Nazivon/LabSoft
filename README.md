# Laboratório de Projetos de Software Livre/Aberto

Postagens para a disciplina de Laboratório de Projetos de Software (ACH2198), realizada no segundo semestre de 2026. 
O projeto escolhido para receber contribuições é o **GrampsWeb**, um software de genealogia gratuito e de código aberto. 
Além do registro de pessoas e relações familiares por meio de árvores, o sistema permite associar eventos, fontes, documentos e locais às informações genealógicas, o que o torna uma ferramenta bastante completa para pesquisadores e usuários interessados em história familiar. 
O projeto também possui uma comunidade ativa e diferentes componentes de software, incluindo a aplicação principal, a API e a interface Web, o que oferece diferentes possibilidades de contribuição.

Disciplina do Bacharelado em Sistemas de Informação (SI), da Escola de Artes, Ciências e Humanidades da Universidade de São Paulo (EACH-USP).
